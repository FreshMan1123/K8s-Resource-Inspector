# K8s巡检管理平台 - 完整项目规划

## 一、项目概述

### 1.1 项目目标
基于现有的K8s-Resource-Inspector CLI工具，构建一个企业级的Web管理平台，提供：
- 可视化规则配置管理
- 一键执行巡检命令
- 定时巡检任务调度
- 历史结果查看与对比
- 操作审计日志记录

### 1.2 技术架构
```
前端: Vue 3 + Element Plus (单页面应用)
后端: Go + Gin框架
存储: 文件系统 (保持现有YAML规则结构)
CLI集成: 直接调用现有inspector二进制文件
调度: 内置Cron调度器 (后期阶段)
```

### 1.3 核心价值
- **降低使用门槛**: 从命令行操作转为Web界面操作
- **提升管理效率**: 可视化规则管理，批量操作支持
- **增强监控能力**: 定时巡检，自动化监控
- **改善决策支持**: 历史趋势分析，问题对比

## 二、完整功能模块

### 2.1 规则管理模块
```
功能清单:
├── 规则展示 (按分类显示现有规则)
├── 规则编辑 (可视化表单编辑)
├── 规则创建 (新建自定义规则)
├── 规则Apply (单个/批量/全局应用)
└── 重复检测 (智能冲突检测)

界面设计:
├── 左侧分类树: 📊节点规则 📦Pod规则 🚀部署规则 🌐服务规则 🔒安全规则
├── 右侧规则列表: ID | 名称 | 监控策略 | 状态 | 操作按钮
└── 规则编辑表单: 基本信息 + 监控条件 + 其他设置
```

### 2.2 巡检执行模块
```
功能清单:
├── 快速巡检 (预设按钮一键执行)
├── 自定义巡检 (参数配置执行)
├── 实时进度 (执行状态显示)
└── 结果展示 (格式化显示结果)

预设巡检按钮:
├── 🏢 集群巡检: 巡检所有节点 | 集群信息 | 节点状态
├── 📦 资源巡检: 巡检所有Pod | 巡检部署 | 巡检服务
└── 🔒 安全巡检: CIS基准检查 | 漏洞扫描 | 镜像安全
```

### 2.3 历史管理模块
```
功能清单:
├── 时间分类查看 (今天/昨天/本周/本月)
├── 巡检结果详情 (完整报告展示)
├── 结果对比 (历史趋势分析)
└── 数据导出 (报告下载)

时间分类视图:
├── 🗓️ 今天 (2024-01-15) [6次巡检]
├── 📅 昨天 (2024-01-14) [8次巡检]
├── 📆 本周 [45次巡检]
└── 📆 本月 [156次巡检]
```

### 2.4 定时任务模块
```
功能清单:
├── 任务管理 (创建/编辑/删除定时任务)
├── 调度执行 (Cron调度器)
├── 通知机制 (邮件/Webhook通知)
└── 执行历史 (定时任务执行记录)

任务配置:
├── 基本设置: 任务名称 | 描述 | 启用状态
├── 巡检配置: 巡检类型 | 目标范围 | 应用规则
├── 执行计划: 执行频率 | 具体时间 | 开始结束时间
└── 通知设置: 通知方式 | 接收人 | 通知条件
```

### 2.5 审计日志模块
```
功能清单:
├── 操作记录 (所有用户操作日志)
├── 变更追踪 (规则变更历史)
├── 日志查询 (按时间/类型筛选)
└── 操作回滚 (基于日志的回滚功能)

记录内容:
├── 规则操作: 创建/修改/删除/Apply规则
├── 巡检操作: 手动执行/定时执行/取消执行
├── 任务操作: 创建/修改/删除/启用/禁用定时任务
└── 系统操作: 配置修改/数据导入导出
```

## 四、启动方式与用户体验

### 4.1 启动方式
```bash
# 用户期望的启动方式
./inspector.exe web --port 9090

# 启动后显示
🚀 启动K8s巡检管理平台...
📱 访问地址: http://localhost:9090
⏹️  按 Ctrl+C 停止服务

✅ 已加载现有规则: 45条
✅ 定时任务调度器已启动
✅ Web界面已就绪
```

### 4.2 用户操作流程
```
规则管理流程:
1. 查看现有规则 → 选择分类 → 浏览规则列表
2. 编辑规则 → 修改参数 → 保存 → Apply规则
3. 创建新规则 → 填写表单 → 验证 → 保存 → Apply规则
4. 批量管理 → 选择多个规则 → 批量操作 → Apply规则

巡检执行流程:
1. 快速巡检 → 点击预设按钮 → 查看执行进度 → 查看结果
2. 自定义巡检 → 配置参数 → 执行巡检 → 查看结果
3. 定时巡检 → 创建任务 → 配置调度 → 自动执行 → 查看历史
```
